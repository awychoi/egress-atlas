## What it is

Egress Atlas is a native macOS observatory for Pi-hole v6 that stages live DNS lookups on a reactive globe. Orbs recoil on impact, blocked DNS orbs raise a red shield, new ones bloom into existence, and old ones shatter into fragments.

Read-only access to Pi-hole, with the API password stored in the macOS Keychain.
